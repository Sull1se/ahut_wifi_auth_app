## 检查方法

1. 按白名单复制源码和必要文档，排除本地文件，独立初始化 Git。
2. 扫描文件名和全部上传候选文本中的私人密钥、访问令牌、硬编码凭据、真实邮箱、手机号、身份证形态、数字账号、本机路径、客户端地址与 MAC；人工复核凭据相关命中。
3. 核查所有公开分支/标签可达提交的文本及作者/提交者邮箱，确认首次导出只有一个匿名快照提交。
4. 逐文件比对运行时代码、资源和 Gradle 配置；公开改动仅限测试样例、说明文档、许可与隐私检查工具。
5. 检查 WebP 元数据并核对唯一 JAR 的官方摘要。核对现有 v1.3.2 APK SHA-256，与签名验收记录一致。

首次快照共 62 个上传候选文件；44 个运行时源码、资源和 Gradle/Wrapper 文件与原项目逐字节一致，全部 Markdown 相对链接有效。使用内存中的虚构内容验证了令牌、数字账号、硬编码凭据、私人邮箱、本机路径及签名文件名六条检测规则，均按预期拒绝。此次没有重新执行 Android 构建或生成 APK；构建验收摘要来自现有产物记录。

脚本可在公开仓库根目录运行：

```powershell
.\scripts\Test-OpenSourcePrivacy.ps1
```

首次快照还可加 `-RequireSingleCommit` 验证只有一次通用署名提交。后续新增正常公开提交后，不再使用此参数。检查只输出文件名和规则名称，不输出疑似秘密的内容。它覆盖 Git 管理文件、待加入的非忽略文件和已提交文本；被忽略的本地构建环境与签名文件不属于上传候选。更新二进制或增加其他文件类型时需人工复核，未知类型会让检查失败。

## 结论与边界

完成规则扫描与人工复核后，当前公开快照未发现真实账号密码、个人联系方式、个人设备地址、发布私钥、密码文件、本机绝对路径或原项目私人历史。

保留的 `10.255.255.154`、`AHUT-FREE`、`AHUT-wifi6` 是应用必须使用的校园网配置。版权使用项目贡献者名称；初始提交邮箱 `contributors@example.invalid` 是不可投递的通用占位，不是个人邮箱。后续维护者可使用 GitHub 提供的 noreply 邮箱。

这是针对当前快照的检查结论，不是对所有未来提交的保证。新增源码、样例、截图、日志和 Release 附件后，应再次检查。应用的 HTTP GET 传输边界与设备测试状态见 [README](../README.md)；隐私检查不等同于校园网真机功能验收。

# v1.3.2

安徽工业大学校园网一键认证 Android 客户端，支持 Android 7.0 及以上。`versionCode = 7`。

## 更新内容

- 增加精确校园 Wi-Fi 工作白名单：`AHUT-FREE`、`AHUT-wifi6`；SSID 未知或不匹配时停止网关操作。
- 自动认证目标与工作白名单独立：首次默认只有 `AHUT-FREE`，`AHUT-wifi6` 需手动加入。
- 主界面与快捷磁贴共用认证协调器，合并状态查询、互斥登录/注销，旧网络响应不更新新连接状态。
- 主动注销暂停当前连接周期自动认证；网络临时错误最多额外重试两次，间隔 5 秒和 15 秒。
- 支持删除无法解密的已存凭据，备份及设备迁移排除敏感偏好。
- 改善安全区域、键盘与窄屏适配，并补齐磁贴锁屏解锁和位置权限流程。
